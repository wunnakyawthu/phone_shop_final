# V12 — Mobile-first workspace polish

No database migration is required for this release.

## Changes
- Mobile app shell is more compact and uses more screen space for content.
- Bottom navigation has larger touch targets but less visual bulk.
- Phone Inventory uses compact two-column product cards on phones.
- Inventory summary cards are swipeable on phones instead of taking multiple full rows.
- Inventory filters use a two-column phone layout with full-width search and brand filter.
- Device detail photos can be swiped horizontally on phones.
- Device detail data uses a compact two-column layout on phones.
- Edit/Delete actions are easier to tap on phones.
- Purchase header and form sections use tighter phone spacing.
- Purchase save action stays above the bottom nav with a clearer compact mobile bar.
- Dashboard cards are denser on phones.
- iPhone/Android browser ergonomics: 16px inputs, tap highlighting disabled, safe-area support, touch-action optimization.
